# simple-notes-manager-147416-147443

This is a modern, light-themed Kotlin Android notes app frontend. Users can create, edit, delete, and search notes via a simple and effective UI, using Material 3 and the specified color scheme.

**Features:**
- Create, edit, and delete notes.
- List and search notes.
- Modern design with Material theming.

_Main UI: Note list with search and floating action button; Note detail for editing/creating, and delete confirmation dialog._
